
# 🎓 AL Paper Tracker (Maths Stream)

A specialized productivity dashboard designed for Sri Lankan A/L students. Track your past paper progress, manage study goals, use a Pomodoro-style timer, and get strategic advice from an AI Study Mentor.

> **Are you a beginner?** Check out the [GET_STARTED.md](./GET_STARTED.md) for a step-by-step installation guide!

## 🚀 Features
- **Daily Paper Log**: Track MCQ, Essay, Pure, and Applied papers.
- **Analytics**: Visualize progress over 14 days.
- **Goals**: Set Weekly/Monthly targets.
- **Timer**: Custom focus/break timer.
- **AI Mentor**: Personalized study tips powered by Gemini.

## 📦 Quick Deploy
1. Push this code to a GitHub repo.
2. Add your `API_KEY` to GitHub Secrets.
3. Enable GitHub Actions for Pages.
