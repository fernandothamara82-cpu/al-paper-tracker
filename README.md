# 🎓 AL Paper & MCQ Platform

A focused dashboard for Sri Lankan A/L students. Track paper progress, manage goals, and now create **interactive Sinhala MCQs** from Physics and Chemistry papers.

> **Are you a beginner?** Check out the [GET_STARTED.md](./GET_STARTED.md) for setup instructions.

## 🚀 Features
- **Daily Paper Log**: Track Physics, Chemistry, and Maths paper progress.
- **Sinhala MCQ Studio**: Generate interactive MCQ quizzes for Physics/Chemistry using pasted paper text.
- **Quiz Review Mode**: Submit answers, get instant score, and read Sinhala explanations.
- **Analytics + Goals**: Measure trend and complete weekly/monthly targets.
- **AI Mentor**: Receive strategic study suggestions via Gemini.

## 📦 Quick Deploy
1. Push this project to GitHub.
2. Add your `API_KEY` to environment/secrets.
3. Run with Vite (`npm run dev`) or deploy static build.
